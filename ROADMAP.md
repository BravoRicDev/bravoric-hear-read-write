# ROADMAP — bravoric-stt-clipboard

## Contesto
Progetto nato dalla necessità di avere dettatura vocale su GNOME con testo pulito da incollare nel terminale e OCR rapido da screenshot, sfruttando endpoint OpenAI-compatible dedicati e instradati tramite router interno (`scrocco-fissone`).

## Configurazione infrastrutturale
- **Provider base**: OpenAI-compatible via VPN
- **Endpoint**: `http://10.9.0.2:4001/v1`
- **Modello unificato (STT / OCR / LLM Cleanup)**: `scrocco-llm-fissone` (il router interno smista verso Whisper, Vision o Chat LLM in base alla richiesta)
- **Chiave API**: `sk-fissone` (env: `SCROCCO_FISSONE_API_KEY`)
- **Certificato CA**: `~/PiAgent/certs/scrocco-fissone.crt`
- **Configurazioni separate**: 2 sezioni di config distinte (una per STT/Audio e una per OCR/Vision), entrambe impostabili con gli stessi parametri endpoint/modello/chiave per scrocco-llm o differenziabili per provider terzi.

## Modalità Operative e Scorciatoie
1. **STT (Voice Push-to-Talk / Toggle)**:
   - **Scorciatoia**: `Alt + Super + R`
   - **Prima pressione**: avvio registrazione audio (feedback visivo nell'icona della barra).
   - **Seconda pressione**: stop registrazione, invio audio all'endpoint OpenAI-compatible (`/v1/audio/transcriptions`), eventuale passaggio di pulizia LLM (`/v1/chat/completions`), scrittura del testo pulito nella clipboard pronto per il terminale.
   - Modalità preferita push-to-talk (hold) o toggle (press start / press stop).

2. **OCR da Screenshot (Vision)**:
   - **Scorciatoia**: `Alt + Super + O`
   - **Flusso**:
     1. L'utente esegue lo screenshot (o cattura l'area negli appunti).
     2. Premendo `Alt + Super + O`, lo script/plugin preleva l'immagine direttamente dalla clipboard (`image/png`).
     3. Invio a scrocco-llm tramite API OpenAI Vision (`/v1/chat/completions` con payload immagine base64 e prompt dedicato per estrazione/trascrizione testo).
     4. Il testo estratto/pulito sovrascrive la clipboard pronto per `Ctrl + V` nel terminale.

3. **Integrazione UI GNOME**:
   - **Icona nella Top Bar di GNOME** (indicatore di stato visivo):
     - Stato idle / pronto
     - Stato registrazione audio in corso (es. rosso/pulsante)
     - Stato elaborazione in corso (STT o OCR)
     - Menu rapido con click (impostazioni, toggle manuale, visualizzazione ultimo output o status connessione router)

4. **Dettatura vocale in streaming / tempo reale (novità)**:
   - **Scorciatoia**: `Alt + Super + S` (`stream-shortcut`)
   - **Flusso**:
     1. Pressione scorciatoia: avvio thread cattura audio `sounddevice` (16kHz mono float32) con VAD locale a energia/silenzio (`silence_threshold`, `min_noise_duration_s`, `max_utterance_s`).
     2. A ogni chunk rilevato o a timeout di frase: codifica in memoria (WAV 16-bit) e invio all'endpoint STT dedicato (indipendente o condiviso).
     3. Due modalità di erogazione:
        - `at_end` (accumulo): i frammenti vengono concatenati e iniettati nella clipboard al termine della registrazione (simile a STT classico ma elaborato a pezzi).
        - `per_chunk` (tempo reale): ogni chunk trascritto viene scritto in `stream_state.json` e notificato all'estensione GNOME. L'estensione, tramite un dispositivo tastiera virtuale (`Clutter.VirtualInputDevice`), incolla automaticamente il testo (`Ctrl+V`) nell'applicazione attiva con pacing configurabile (`paste_delay_ms`).
     4. Seconda pressione: stop immediato, completamento dell'eventuale chunk residuo, ripristino clipboard originale e stato `idle`.

## Funzionalità nel dettaglio
1. **Modulo STT**:
   - Cattura microfono
   - Trascrizione OpenAI-compatible
   - Pulizia testo con LLM (opzionale e configurabile)
   - Copia automatica negli appunti (`wl-copy` / clipboard nativa GNOME)
2. **Modulo OCR / Vision**:
   - Lettura immagine da clipboard Wayland/X11
   - Chiamata OpenAI Chat Completion con payload Vision
   - Prompt di sistema per estrazione testo grezzo o formattato senza chiacchiere LLM
   - Copia testo estratto negli appunti
3. **Pannello / Extension GNOME**:
   - Icona nella barra superiore per stato e controllo rapido
   - Scorciatoie registrate a livello di sistema / Shell
4. **Configurazione Modulare**:
   - Sezione Audio/STT (endpoint, model, key)
   - Sezione Vision/OCR (endpoint, model, key)
   - Sezione LLM Cleanup (prompt personalizzabile, switch on/off)

## Risposte alle domande di integrazione
- **Display server**: Wayland
- **Uso OCR**: testo da immagine, codice, porzioni di terminale, raramente grafici
- **Microfono**: integrato, ambiente silenzioso, usa quello configurato in GNOME al momento
- **Output OCR**: doppia iniezione clipboard — prima testo grezzo trascritto, poi testo elaborato LLM. L'utente ha estensioni clipboard history e decide quale usare.
- **Pulizia LLM**: prompt configurabile dall'utente
- **Lingua audio**: prevalentemente italiano
- **Durata registrazione**: sessioni brevi (<1 min continuo), inizio/fine con toggle
- **Indicatore visivo**: sì (icona barra)
- **Avvio tool**: on-demand con scorciatoia

## Risposte domande 16–20 + requisiti fallback
- **Notifiche**: GNOME native
- **Formato audio**: OGG (leggero, serve ffmpeg)
- **Toggle recording**: ferma dopo 1s (configurabile)
- **LLM cleanup**: `scrocco-llm-fissone-200k` (configurabile)
- **Errore trascrizione**: ritenta automaticamente
- **OCR ripasso LLM**: opzionale, stesso modello trascrizioni con prompt dedicato configurabile
- **Audio Whisper**: default
- **Screenshot**: qualsiasi immagine, modelli image2text con prompt configurabile
- **Aggiornamenti**: manuale (uso personale, nessun auto-update)
- **Output STT**: stesso schema OCR — testo grezzo + ripasso LLM opzionale (già previsto)
- **Strumento in uso**: solo durante registrazione/elaborazione; configurazione accessibile normalmente
- **OGG codec**: Opus, qualità WhatsApp (~16kHz, ~16kbps)
- **Lingua OCR**: rilevamento automatico
- **Output**: solo clipboard, nessun TTS

## Catena di fallback (3 livelli)
- 3 provider/modelli configurabili separatamente
- Fallback automatico se un livello è offline / modello non trovato
- Timeout configurabile per livello
- Livello 1 (scrocco-llm): timeout 120s
